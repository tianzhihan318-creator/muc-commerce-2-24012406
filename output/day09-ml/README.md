## 用自己的话回答

- 什么是特征，什么是标签：特征是模型用来做判断的输入数据，包含用户的各种属性和行为信息；标签是模型要预测的目标答案，即用户是否真实流失。特征和标签构成了一对训练样本，模型通过大量这样的样本学习从特征到标签的映射规律。
- 为什么要保留测试集：测试集用于模拟模型从未见过的新用户，评估模型的真实泛化能力。如果只在训练集上评估，模型可能只是记住了训练数据而没有学到通用规律，导致上线后准确率远低于训练时的表现。
- 为什么83%准确率仍可能没有用：如果数据集中流失用户只占17%，那么一个永远预测"不流失"的模型也能达到83%准确率，但它无法识别任何一个流失用户，在实际业务中毫无价值。因此评估模型时不能只看准确率，还要关注召回率等指标。
